## 常见问题

### SuperGrok 年费中途能退吗？

网页端不自动退剩余周期，要走官方支持渠道申请；App 商店订阅取消后服务保留到当期结束，当期不退。所以年费下单前，最好先用月付验证一个月。

### SuperGrok 和 X Premium 是一回事吗？

不是，这是两家公司的两个订阅。X Premium（3–40 美元/月）是 X 平台的会员，附带有限的 Grok 额度；SuperGrok 是 xAI 出售的独立 AI 订阅，额度高得多，买其中一个不包含另一个。唯一的交叉是 Heavy 档附赠 X Premium+。

### 月付 30 美元，比 Claude Pro 贵在哪？

Claude Pro 是 20 美元/月，SuperGrok 贵出一半。多出来的 10 美元主要买的是 X 实时数据流和 Grok Bot。如果你主要用来写作、分析文档，便宜的替代品完全够用；如果工作依赖 X 上的实时信息，这 10 美元才花得有意义。

### SuperGrok 涨过价吗？

没有。标准档自 2025 年 2 月随 Grok 3 上线就是 30 美元，Heavy 自 2025 年 7 月随 Grok 4 上线就是 300 美元，Lite 自 2026 年 3 月上线就是 10 美元，至今零调价记录。同期 X Premium+ 已经翻了一倍多，对比之下相当克制。

### 各档位的上下文长度差多少？

按用户社区整理的口径：免费版有效上下文约 32k–64k tokens，Lite 和 X Premium 约 128k，更高档位约 256k；底层模型在 API 场景能到 200 万，但日常聊天里“不跑偏”的长度以档位为准。Grok 用滑动窗口加项目持久记忆，没有硬性的单聊轮数限制逼你重开对话。

### Grok Bot 是不是所有档位都有？

标准档、Plus、Heavy 有，开通方式是把 Grok 账号绑定到 Cursor 账号，用量在 Cursor 侧单独计量、不占聊天额度；Lite 不含，团队档和企业版不能绑定。另外，如果只冲着 Grok Bot 来，Cursor Pro 每月 20 美元也包含它，不一定非买 SuperGrok 不可。
